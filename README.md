# 🤖 AI Career Assistant Pro

An AI-powered web application that helps students with career guidance, resume analysis, and interview preparation using Generative AI.

---

## 🚀 Features

### 💬 AI Career Chatbot
- Ask questions about DSA, placements, resume, and interviews
- Powered by Google Gemini AI
- Provides structured and detailed responses

### 📄 Resume Analyzer (ATS System)
- Upload your PDF resume
- Get:
  - ATS Score (0–100)
  - Strengths & Weaknesses
  - Missing Skills
  - Recommended Job Roles
  - Improvement Suggestions

### 🔐 User Login System
- Simple session-based login
- Username validation implemented

### 🧹 Chat Management
- Clear chat functionality
- Maintains session-based chat history

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Flask (Python)
- **AI Integration:** Google Gemini API
- **PDF Processing:** PyPDF2
