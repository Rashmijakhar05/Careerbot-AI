# 🤖 AI Career Assistant (Flask + Google Gemini AI)

An intelligent AI-powered web application designed to help students with **career guidance, resume analysis, DSA preparation, interview readiness, and job support** using Google Gemini AI.

---

## 🚀 Live Demo
👉 https://careerbot-ai-87ik.onrender.com

---

## ✨ About the Project

This project is a **full-stack AI-based Career Assistant** that acts like a smart mentor for students and freshers. It combines AI chatbot capabilities with resume analysis features to provide personalized career guidance.

The system is designed to simulate real-world career assistance tools used in modern EdTech platforms.

---

## 💡 Key Features

### 💬 AI Chatbot (Gemini Powered)
- Intelligent conversational AI using Google Gemini API
- Helps with:
  - Data Structures & Algorithms (DSA)
  - Resume building tips
  - Interview preparation strategies
  - AI/ML fundamentals
  - Career roadmap guidance

---

### 📄 Resume Analyzer
- Upload PDF resumes
- Extracts and processes resume content using PyPDF2
- Provides:
  - ATS Score (Applicant Tracking System score)
  - Strengths in resume
  - Missing technical skills
  - Recommended job roles
  - Improvement suggestions

---

### ⚡ Web Application Features
- Clean and modern UI design
- Real-time chat interface
- Quick action prompts for faster interaction
- Voice input support for user convenience
- Session-based user experience
- Responsive layout for all devices
